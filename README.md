# immobilieranddesign.fr

Site vitrine d'Immobilier & Design (Saissac, Aude), servi par GitHub Pages depuis la branche `main`.

- `index.html` : page unique (héros, services, à propos, contact).
- `mentions-legales.html`, `404.html` : pages secondaires, même feuille de style.
- `css/site.css` : toute la mise en forme. Aucun JavaScript, aucun cookie.
- `fonts/` : Archivo (licence OFL), hébergée ici pour éviter tout appel à Google Fonts.
- `images/` : photos en WebP, logo, image de partage `og.jpg`.
- `about_us.html`, `services.html`, `contact_us.html` : anciennes adresses, redirigent vers les ancres de la page unique.

Pour modifier un texte, éditer `index.html` directement ; pour changer le numéro de téléphone, chercher `+33765550417` et `07 65 55 04 17`.
